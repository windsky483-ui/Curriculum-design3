# MPU6050 动作识别项目

## 项目用途

项目用于 STM32F407 采集 MPU6050 六轴传感器数据，并通过串口发送至电脑上位机。固件包含静止、走路、跑步和跌倒四类动作识别功能，上位机用于实时显示数据、采集数据和训练随机森林模型。

## 运行顺序

1. 使用 Keil 打开 `MPU6050_Test.uvprojx`，编译并将生成的固件烧录到 STM32F407。
2. 安装 Python 依赖后，运行 `上位机\mpu6050_monitor.py`，或双击 `上位机\启动上位机.bat`。
3. 在上位机中选择串口并连接开发板，即可查看实时数据和识别结果。
4. 如需重新训练模型，准备带标签的 CSV 数据集后运行 `模型训练\训练随机森林.py`；训练完成后会生成新的 `model.h`，重新编译固件即可使用。

## 环境要求

- STM32F407 开发板、MPU6050 模块和串口连接
- Keil MDK-ARM，支持 ARM Compiler 6
- Python 3.10 或更高版本
- Python 依赖：`pyserial`、`PyQt5`、`pyqtgraph`、`numpy`
- 训练模型额外需要：`scikit-learn`
